- **왼쪽 프리셋 목록**: 1:1 썸네일 카드 10개. 썸네일은 프리셋의 대표 시각(`posterAt`) 한 프레임이고, 마우스를 올리면 그 카드만 움직인다. 고른 카드는 테두리로 표시한다.
- **가운데 프리뷰**: 1:1 캔버스(1080 × 1080 좌표). 재생·일시정지, 처음부터, 반복 토글, 진행 막대(끌면 그 시각에서 멈춤), 현재·전체 시간. **바탕**은 보기 전용(체커·다크·라이트)이고 출력에는 들어가지 않는다. 아래에 출력 크기와 **영상 복사**·**코드 복사**.
- **오른쪽 컨트롤러**: 타이포그래피는 맨 위에 문장 입력. 이미지는 맨 위에 [이미지 슬롯](#이미지-슬롯). 그 아래 공통·글자(또는 이미지)·이 효과 묶음, 배경, **기본값으로**.
- **이미지 하위 탭**: 문장 입력 자리에 이미지 슬롯 8칸이 온다. 지금 프리셋이 쓰는 칸은 밝게, 쓰지 않는 칸은 흐리게 보인다.
- 좁은 화면(1024px 아래)에서는 목록 → 프리뷰 → 컨트롤러 순으로 세로로 쌓는다.
- 색·글꼴·버튼·슬라이더는 `tokens.css`·`base.css`와 스튜디오 컨트롤(슬라이더 + − + 숫자 칸, 색 스와치)을 그대로 쓴다. 라이트·다크 모드를 모두 맞춘다.

| 동작 | 결과 |
|---|---|

| 컨트롤러 조정 | 프리뷰에 바로 반영. 값은 프리셋마다 브라우저에 기억한다 |

## 모션 런타임

### 그리기 원칙 (R3)

- 모든 모션은 **1080 × 1080 좌표의 Canvas 2D**에 **시간 t의 함수**로 그린다. 같은 t, 같은 값이면 언제나 같은 그림이다. 무작위는 씨앗을 가진 의사 난수만 쓴다.
- 프리뷰(rAF로 t를 흘림), 영상(t를 한 프레임씩 넘겨 그림), 코드 복사(같은 함수의 소스)가 **같은 그리기 함수**를 쓴다. 미리 만든 영상·이미지 시퀀스는 두지 않는다.
- 3D처럼 보이는 모션(플립·360°·캐러셀)은 Canvas 2D의 가짜 3D(이미지를 세로 띠로 나눠 높이를 달리 그림)로 만든다. WebGL·새 의존성은 쓰지 않는다(`presentation-motion` 스킬과 같다).
- 출력 크기가 2160이면 같은 좌표계를 2배로 그린다.

### 데이터 모델

`src/shared/motions.ts`(줄임):

```ts
type MotionKind = "typography" | "image";

type MotionParam =                       // showIf: 다른 값이 그 값일 때만 보인다(예: 배경색은 배경 = 단색일 때)
  | { id; label; type: "range"; min; max; step; default: number; unit?; showIf? }
  | { id; label; type: "select"; options: { value; label }[]; default: string; showIf? }
  | { id; label; type: "color"; default: string; showIf? }
  | { id; label; type: "toggle"; default: boolean; showIf? };

type MotionPreset = {
  id: string;                 // "typo-eye-lens", "img-card-fan"
  kind: MotionKind;
  name: string;               // "볼록 렌즈"
  summary: string;            // 목록·툴팁 한 줄
  timing: "intro" | "cycle";  // 등장형: 등장 → 유지 → (반복이면 퇴장). 지속형: 한 주기를 끊김 없이 반복
  strength: RangeParam;       // 공통 "세기"가 움직이는 이 프리셋의 주 값
  params: MotionParam[];      // 이 효과 전용 컨트롤
  defaults?: MotionValues;    // 공통 기본값 덮어쓰기(이미지 크기·비율 등)
  slots?: number | string;    // 이미지 프리셋: 쓰는 슬롯 수, 또는 그 수를 정하는 param id("count")
  posterAt: number;           // 목록 썸네일 시각(0–1). 등장형은 등장 구간, 지속형은 한 주기의 비율
  duration: (input: MotionInput, kit: MotionKit) => number;   // 1배속 등장 길이 또는 한 주기(초)
  outro?: (input: MotionInput, kit: MotionKit) => number;     // 반복 전에 나가는 길이(초)
  draw: (ctx: CanvasRenderingContext2D, frame: MotionFrame, kit: MotionKit) => void;
};                            // duration·outro·draw는 자기완결 함수: 인자만 쓴다. 코드 복사가 소스를 그대로 붙인다

type MotionFrame = {
  t: number;                  // 타임라인 초(1배속): 등장 0 → intro, 유지 동안 멈춤, 그다음 퇴장. 지속형은 0 → 한 주기
  clock: number;              // 멈추지 않는 시계(커서 깜빡임 등)
  realT: number;              // 실제 초
  scale: number;              // 모션 단위당 장치 픽셀(1080 출력 = 1, 2160 = 2)
  values: MotionValues;       // 공통 + 전용 값
  text: MotionLayout | null;  // 타이포그래피: 글자별 위치·크기·줄·단어·쓰는 차례·강조 단어인지(strong)
  images: CanvasImageSource[];// 이미지: 슬롯 순서(장수만큼 되풀이)
  timeline: MotionTimeline;
  surfaces: Map<string, HTMLCanvasElement>; // 렌즈·블러·카드용 임시 캔버스
  ctx: CanvasRenderingContext2D;
};
```

- `MotionKit`: 이징, 보간, 씨앗 난수, 텍스트 경로, 이미지 맞춤(cover·contain), 둥근 사각형, 띠 나눠 그리기(가짜 3D) 같은 도우미. 각 도우미도 자기완결 함수다.
- 글자 배치(`TextLayout`)는 순수 함수다. 문장을 단어 단위로 줄바꿈해 여백 안에 넣고, **자동 크기**면 넘치지 않는 가장 큰 크기를 고른다. 글자마다 x·y·폭·줄·단어 번호를 돌려준다. 글자 폭 재기는 함수로 받아(브라우저는 `measureText`) 테스트할 수 있다.
- 글꼴은 앱에 있는 Montserrat·Pretendard·Roboto다. 그리기 전에 `document.fonts.load`로 그 굵기를 불러온다(스튜디오 정지 화면과 같다).

### 공통 컨트롤

모든 프리셋에 있다. **세기**는 프리셋마다 그 효과의 주 값을 가리키고, 라벨에 뜻을 함께 쓴다(예: `세기 · 배율`).

| 컨트롤 | 형식 | 범위 | 기본 | 뜻 |
|---|---|---|---|---|
| 속도 | 슬라이더 | 0.25–3× | 1× | 모든 시간을 이 배수로 줄이거나 늘린다 |
| 세기 | 슬라이더 | 프리셋마다 | 프리셋마다 | 아래 표의 "세기" |
| 반복 | 토글 | — | 켬 | 끄면 1회 재생. 붙여 넣은 영상 레이어의 재생(1회·반복)이 된다 |
| 유지 | 슬라이더 | 0–5초 | 1.5초 | 등장형만. 다 나타난 뒤 머무는 시간 |
| 배경 | 선택 + 색 | 투명·단색 | 투명 | 출력 영상의 배경. 단색이면 MP4, 투명이면 WebM |

## 이미지 소스와 교체 (R9, R10)

### 이미지 슬롯

- 모든 이미지 프리셋이 함께 쓰는 **순서 있는 8칸**이다. 프리셋을 바꿔도 슬롯은 그대로다.
- 칸마다 썸네일, **바꾸기**(에셋에서 고르기 · 내 파일), **비우기**가 있다. 칸끼리 끌어서 순서를 바꾸고, 파일을 칸에 끌어 놓으면 그 칸이 바뀐다.
- 내 파일은 이 브라우저의 IndexedDB(`ax-motion-files`)에 넣고, 칸은 `file:<id>`로 가리킨다. 디스크에는 쓰지 않는다. 영상으로 붙일 때 영상에 구워지므로 원본은 필요 없다.
- 채운 칸이 필요한 장수보다 적으면 채운 칸을 되풀이해 쓴다. 칸이 모두 비었거나 그림을 불러오지 못하면 번호를 적은 대신 그림으로 그린다.

고를 수 있는 범위는 [확인한 사항](#확인한-사항) Q1대로 아래 세 묶음 전부다.

- 기본 슬롯(예시)은 그래픽 라이브러리 8점이다: 실크스크린 꽃·크로매틱 리본·레드 블루 아치·인디고 무지개·시트러스 아치·코랄-블루 발광 링·방사형 꽃잎·블루 종이(`src/motion-assets.ts`의 `EXAMPLE_SLUGS`). 라이브러리에 없는 것은 라이브러리 순서대로 채우고, 라이브러리가 없으면(`public/data/index.json`이 없을 때) 비운다. 프로젝트·Conference 그림은 기본에 넣지 않는다(2026-11-26 요청, P3-07).
- 이 바꿈 전에 저장된 슬롯 목록(`slotsVersion` 없음)은 한 번 예시로 돌아간다. 앱을 열 때 어느 슬롯도 가리키지 않는 내 파일은 지운다.
- 영상으로 내보내야 하므로 모든 이미지는 캔버스를 더럽히지 않게(`crossOrigin = "anonymous"`) 불러온다. Motions 전용 로더(`loadMotionImage`)가 주소마다 한 번만 불러 둔다.

|---|---|
| 크기 | 1:1. 1080 × 1080(기본) 또는 2160 × 2160 |
| 프레임 | 30fps |
| 길이 | 등장형: 등장 + 유지. 지속형: 한 주기. 최대 20초 |
| 투명 배경(기본) | WebM(VP9 + 알파, `alpha: "keep"`) |
| 단색 배경 | MP4(H.264). Conference 동영상 내보내기와 같은 `mediabunny` 경로 |
| 포스터 | PNG 한 장. 등장형은 등장이 끝나 자리 잡은 프레임, 지속형은 대표 시각(`posterAt`) 프레임 |

- t를 한 프레임씩 넘기며 그려 인코딩한다(실시간 녹화가 아니므로 느린 프레임이 빠지지 않는다). 진행률과 취소가 있다.

### 앱 안 클립보드

- 시스템 클립보드는 영상 파일을 담지 못한다. 그래서 **영상 복사**는 앱 안 클립보드(`src/motion-clip.ts`)에 영상 Blob·포스터·정보(프리셋, 크기, 길이, 반복, 배경)를 둔다. Motions 상단에 `복사한 영상: …`으로 보인다.
- 같은 탭 안에서 Presentation으로 옮겨 가도 남는다. 새로고침하면 사라진다.

### 붙여넣기

Presentation 편집 캔버스에서 ⌘V(Ctrl+V):

1. 시스템 클립보드에 파일이 있으면 지금처럼 그 파일을 먼저 붙인다.
2. 아니고 앱에서 마지막으로 복사한 것이 모션이면(`clipKind = "motion"`) 모션 영상을 붙인다.
3. 아니면 지금처럼 레이어를 붙인다.

코드 모드인 페이지에는 붙이지 않는다(파일 붙여넣기와 같다). 배포 사이트에서도 붙일 수 있고 그 브라우저에만 저장한다([확인한 사항](#확인한-사항) Q5).

| | localhost | 배포 사이트 |
|---|---|---|
| 영상 저장 | 열린 페이지 폴더에 `motion-<presetId>-<시각>.webm`(또는 `.mp4`) | 브라우저 IndexedDB(`ax-studio-uploads`). src는 `upload:<id>.webm`처럼 확장자를 붙여 영상으로 인식되게 한다 |
| 포스터 | 같은 폴더에 `<이름>.poster.png`. 컨트롤 패널 **이 페이지** 목록에서는 숨긴다 | 같은 레코드 |
| 레이어 | 영상 이미지 레이어. 마우스 위치(없으면 가운데)에 원래 크기(1080 또는 2160px)로 놓는다. 재생 = 반복이면 반복, 아니면 1회 | 같음 |

- 붙인 뒤 `모션 영상을 붙여 넣었습니다.` 토스트. 되돌리기(⌘Z)로 지울 수 있다.
- 영상의 정지 그림은 지금 모두 `captureVideoPoster`가 뽑은 **첫 프레임**이다: 한 장 PNG·PDF, 덱 PDF·PPTX, 레일·프로젝트 카드 썸네일. 등장형 모션은 첫 프레임이 비어 있으므로, `captureVideoPoster`가 포스터가 있으면 포스터를 쓰게 한다. 발표 모드와 HTML 내보내기는 영상을 그대로 재생한다.
- 사이트 빌드는 덱이 쓰는 영상 옆의 포스터(`<이름>.poster.png`)도 함께 `presentation-media/`로 복사한다. 그래야 배포 사이트의 정지 그림도 포스터를 쓴다.

## 코드 복사 (R5)

- **코드 복사**는 지금 프리셋·값·문장·이미지 그대로 재생되는 **HTML 한 조각**을 시스템 클립보드에 넣는다: `<canvas>` 하나 + 인라인 `<script>`(kit 도우미, 그 프리셋의 `draw` 소스, 값 JSON, 재생 루프) + 글꼴 `<link>`.
- 외부 스크립트·라이브러리는 없다. kit과 프리셋의 `duration`·`outro`·`draw`가 자기완결 함수라 함수 소스를 그대로 붙인다(빌드에서 줄여 쓴 코드여도 동작한다). 스크립트 맨 앞의 `const __name = (target) => target;`는 개발 서버가 함수 이름을 지키려 `__name(…)`으로 감싼 소스도 돌게 한다. 테스트가 20종을 붙인 소스로 다시 만들어 그려 본다.
- 이미지: 에셋은 원래(절대) 주소, 내 파일은 data URL로 넣는다. 코드가 5MB를 넘으면 복사 전에 묻는다. 재생기는 그림을 CORS 없이 불러온다(그림 픽셀을 읽는 이미지 프리셋이 없다). 그래서 어느 서버의 그림이든 보인다.
- 이 코드는 웹 페이지·다른 도구에 붙여 쓰는 것이다. Presentation **Code** 탭은 `<script>`를 지우므로 그곳에서는 재생되지 않는다. Presentation에는 영상으로 붙인다([확인한 사항](#확인한-사항) Q3).

### 3-1 모션 런타임

계획: `src/shared/motions.ts`에 `MotionPreset`·`MotionParam` 형식, 값 기본값·범위 맞춤(저장된 값이 범위 밖이면 고침), 속도를 반영한 회차 길이·단계(등장·유지·퇴장) 계산, 이징, 씨앗 난수, 글자 배치(줄바꿈·자동 크기, 폭 재기 함수 주입)를 둔다. `src/motions/kit.ts`에 그리기 도우미를 자기완결 함수로 둔다.

검증: 단위 테스트로 기본값·범위 맞춤, 속도 2×면 길이가 절반, 같은 씨앗이면 같은 수열, 기본 문장이 1080 칸 안에 줄바꿈되어 들어가고 자동 크기가 넘치지 않음.

### 3-2 네비·주소·화면 골격

계획: 헤더 네비에 `Motions`(Presentation 오른쪽), `src/router.ts`에 [주소](#정보-구조와-주소), `src/views/motions.ts`에 하위 탭과 세 칸 레이아웃, `src/styles/motions.css`. 다른 탭처럼 앱 데이터(Conference·프로젝트 목록·그래픽 라이브러리)를 읽은 뒤 그린다.

검증: 탭 순서가 Projects → Presentation → Motions다. 주소를 직접 쳐도, 뒤로·앞으로를 눌러도 맞는 하위 탭·프리셋이 열린다. 라이트·다크와 좁은 화면에서 깨지지 않는다.

### 3-3 프리뷰와 컨트롤러

계획: 1:1 프리뷰(재생·일시정지·처음부터·반복·진행 막대·바탕), 프리셋 목록(대표 프레임 썸네일, 올리면 재생), 스키마에서 만드는 컨트롤러(슬라이더·선택·색·토글·입력), 프리셋별 값 기억, **기본값으로**. 프리뷰는 화면에 보일 때만 그리고, 탭을 떠나면 멈춘다.

검증: 컨트롤러를 움직이면 다음 프레임에 반영된다. 새로고침해도 프리셋별 값이 남는다. **기본값으로**는 그 프리셋만 되돌린다. 진행 막대를 끌면 그 시각의 프레임이 보인다. 키보드만으로 프리셋 고르기·슬라이더 조정이 된다.

### 3-4 타이포그래피 10종과 문장 입력

계획: [타이포그래피 표](#타이포그래피-프리셋-10종-r8)의 10종, 문장 입력(라이브 반영, 0.5초 멈추면 등장형 다시 재생, 비면 기본 문장).

검증: 10종이 각자 표의 컨트롤러로 조정된다. 입력란에 타이핑하면 프리뷰가 바로 바뀌고, 지우면 `AX gives people room to grow`가 보인다. 한글 문장도 줄바꿈·자동 크기가 맞다. 프로그레시브 블러가 레이어 **블러로 나타나기**와 같은 시간감으로 보인다. 프리뷰가 30fps로 끊기지 않는다(볼록 렌즈·블러 포함).

### 3-5 이미지 슬롯·에셋 고르기·내 파일 교체

계획: [이미지 슬롯](#이미지-슬롯) 8칸, 에셋 고르기 대화상자(프로젝트·Conference·그래픽 라이브러리), 내 파일(파일 고르기·끌어 놓기), 칸 순서 바꾸기, 기본 슬롯.

검증: 각 칸을 에셋·내 파일로 바꾸고 새로고침해도 남는다. 칸 순서를 바꾸면 프리뷰의 카드 순서가 바뀐다. 다른 출처 이미지(그래픽 라이브러리)를 써도 영상·코드 복사가 막히지 않는다.

### 3-6 이미지 10종

계획: [이미지 표](#이미지-프리셋-10종-r9)의 10종.

검증: 10종이 각자 표의 컨트롤러로 조정된다. 장수를 바꾸면 쓰는 칸 수가 바뀐다. 지속형은 한 주기 끝과 처음이 이어진다(영상을 반복 재생해도 튀지 않음). 360°·플립·캐러셀이 원근 값에 따라 자연스럽다.

### 3-7 영상 만들기·앱 안 클립보드·Presentation 붙여넣기

계획: [영상 만들기](#영상-만들기), [앱 안 클립보드](#앱-안-클립보드), [붙여넣기](#붙여넣기). 스튜디오 붙여넣기 처리에 모션 순서를 더하고, `captureVideoPoster`가 포스터를 먼저 쓰게 한다. 페이지 폴더 목록에서 `*.poster.png`를 숨기고, 사이트 빌드가 영상의 포스터를 함께 복사하게 한다.

검증: 투명·단색 각각 영상이 만들어지고 길이·크기가 맞다. 취소하면 아무것도 복사되지 않는다. Presentation에서 ⌘V로 붙이면 영상 레이어가 생기고, localhost에서는 그 페이지 폴더에 파일이 생긴다. 반복 끔이면 1회 재생한다. 발표 모드·HTML 내보내기에서 재생되고, 한 장 PNG·PDF, 덱 PDF·PPTX, 레일 썸네일에는 포스터가 들어간다. 시스템 클립보드의 그림 파일·레이어 복사·페이지 복사 붙여넣기는 지금처럼 동작한다.

### 3-8 코드 복사

계획: [코드 복사](#코드-복사-r5).

검증: 복사한 HTML을 빈 HTML 파일에 붙여 Chrome에서 열면 프리뷰와 같은 모션이 같은 값으로 재생된다(20종 모두). 테스트가 20종의 내보낸 스크립트를 새 범위에서 실행해 참조 오류가 없는지 확인한다.

### 3-9 배포 사이트

계획: [localhost와 배포 사이트](#localhost와-배포-사이트) 표대로. 배포 사이트의 영상 붙여넣기는 IndexedDB에 넣는다.

검증: 빌드 미리보기(`vite preview`)에서 20종 프리뷰·영상·코드 복사가 되고(빌드로 줄인 코드에서 복사한 HTML도 재생된다), 붙인 영상이 새로고침 뒤에도 그 브라우저에서 재생된다. localhost에서 모션을 붙여 기본값 세팅한 덱을 빌드하면 영상과 포스터가 함께 복사되고, 미리보기의 PDF·PPTX에 포스터가 들어간다. 투명 영상을 만들 수 없는 브라우저에서는 단색으로 만들라고 안내한다.

### 3-10 테스트와 문서

계획: `scripts/test-motions.ts`(프리셋 20종 등록·id 중복 없음·종류별 10종, 스키마 기본값이 범위 안, 저장값 범위 맞춤, 기본 문장, 글자 배치, 속도·길이, 씨앗 난수, 20종을 여러 시각에 그려 보기, 코드 내보내기 실행, 붙여 넣는 파일·포스터 이름, `ax-motions` 저장, Motions 주소)와 `package.json`의 `test:motions`. ⌘V 순서는 브라우저에서 확인한다. README, Dev Phase 1·2 문서의 네비 설명, `.cursor/skills/presentation-motion`(Motions 탭에서 만드는 방법), 이 문서의 상태를 갱신한다.

검증: `npm run test:motions`, `test:projects`, `test:studio`, `test:conference`, `tsc --noEmit`, `npm run build`가 통과한다.

## 구현 결과

2026-11-26 구현. 3-1–3-10을 모두 마쳤다. 파일은 [바뀐 파일](#바뀐-파일).

계획과 달라진 점:

- 프리셋은 종류별로 한 파일(`src/motions/typography.ts`, `src/motions/image.ts`)에 둔다. 저장은 `src/motions-store.ts`로 나눴다. 프리뷰 루프는 `src/views/motions.ts`에 있고, `motion-render.ts`는 영상과 포스터만 맡는다.
- 공통 값과 id가 겹치지 않게 3D 캐러셀의 고리 반지름은 `ring`, 무한 마퀴의 속도는 `pace`(라벨 "흐르는 속도")다.
- 포스터는 등장형이면 등장이 끝난 프레임, 지속형이면 `posterAt` 프레임이다. 목록 썸네일은 `posterAt`을 쓴다(등장형은 등장 구간의 비율).
- 붙인 영상의 포스터는 서버 페이지 파일 목록과 컨트롤 패널에 나오지 않고, 영상을 지우면 함께 지워진다.
- 편집기 변경은 지금처럼 덱 동작(페이지 이동 등) 때 브라우저에 저장된다. 붙인 모션 영상도 같다.
- 구현 뒤 요청(2026-11-26):
  - 이미지 예시는 그래픽 라이브러리만 쓴다(P3-07).
  - 타이포그래피는 한 문장 안에서 굵기를 나눈다. 강조 단어(기본 AX·people·grow)는 강조 굵기, 나머지는 기본 굵기다(P3-13). 처음에는 프리셋마다 얇은 서체와 굵은 서체를 나눴다가 이렇게 바꿨다. 목록 카드는 프리셋마다 다른 서체를 불러온 뒤 그린다.

### 구현 뒤 추가 (2026-11-28)

요청: 모션 타이포그래피의 자간·행간, 선택 상태의 회색, Projects 제목, Presentation 레이어 모션.

- **자간·행간**: 타이포그래피 컨트롤러 맨 위(문장·강조 단어 바로 아래)에 `자간·행간` 묶음으로 옮겼다(값 id는 그대로 `spacing`·`lineHeight`).
- **선택 상태 회색**: 디자인 시스템(`src/shared/tokens.css`)에 모드별 `--selected`·`--on-selected`(다크 `#3A3A40`/`#FCFCFF`, 라이트 `#E2E2E8`/`#010102`)와 아이콘용 `--neutral`(`#8B8B94`)을 더했다. 하늘색(`--soft`)이던 선택 칩·하위 탭·보기 전환·반복 버튼·강조 단어 칩·네비 버튼 호버·프로젝트 카드 아이콘이 이 회색을 쓴다(P3-16).
- **Projects 제목**: 25.6px(32px의 80%, 좁은 화면 20.8px), 폴더 아이콘은 22px 면 아이콘, 색 `--neutral`.
- **레이어 모션**(P3-15):
  - 편집 화면에서 텍스트 하나나 이미지 하나(영상·gif 제외)를 고르면 선택 상자 위(위쪽이 좁으면 아래)에 **텍스트 모션**·**이미지 모션** 버튼이 나온다. 모션이 있으면 `텍스트 모션 · 웨이브`처럼 이름이 붙는다.
  - 버튼은 팝업(`src/views/layer-motion.ts`)을 연다: 프리셋 10종(그 레이어로 그린 썸네일), 레이어 그대로의 미리보기, 공통·이 효과 컨트롤러(이미지는 카드 그림자도), **적용**·**취소**·**모션 없애기**. 컨트롤러는 Motions 탭과 같은 코드(`src/views/motion-fields.ts`)다.
  - 레이어에 `motion: { preset, values }`(프리셋 처음 값과 다른 값만)로 저장한다. 되돌리기·복사·기본값 세팅(`deck.json`)에 함께 들어간다.
  - 재생: 모션은 1080 정사각형을 그대로 쓰고, 정사각형을 레이어 둘레에 놓아 레이어를 정확히 덮게 키운다(`src/motions/layer.ts`). 텍스트는 편집기의 줄바꿈·줄 높이·기준선·글꼴·색으로 글자 배치를 만들어 정지 글자와 같은 자리에서 움직이고, 이미지는 자른·보정한 그림이 프리셋의 카드가 된다.
  - 편집 화면: 페이지를 열 때, 레일에서 그 페이지를 다시 누를 때, 적용 직후 재생한다. 반복이 꺼진 모션은 한 번 뒤 정지 레이어로 돌아간다. 슬라이드를 누르면 멈추고 정지 레이어가 보인다. 재생 중인 레이어는 편집 캔버스에서 빠지므로 레일의 라이브 썸네일에 모션을 겹쳐 그리고, 페이지 썸네일을 찍을 때는 먼저 멈춘다.
  - 발표 모드는 같은 재생을 쓴다. HTML 내보내기는 모션 레이어를 캔버스로 바꿔 그 자리(아래위 순서 유지)에서 재생한다(kit·쓰인 프리셋만 담고, 글자는 내보내기에 넣은 글꼴로 그린다). PDF·PPTX·PNG는 정지 레이어다.
  - 한계: 편집 화면·발표 모드에서 재생 중인 모션은 다른 레이어보다 위에 그린다. 그라데이션 글자는 단색으로 움직인다. 블러 등장과 모션이 함께 있으면 모션만 재생한다.
